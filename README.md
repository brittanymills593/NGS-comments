This streamlit hosted website is used to retrieve haemonc NGS comments. Test_NGS_dashboard.py hosts the website, found at https://ngs-comments.streamlit.app/. Functions are written in dashboard_functions.py and these are used in the dashboard script. The script searches an excel file, NGS_comments_automation.xlsx saved on iPassport as GEN-DOC 23: Additional interpretation comments for haemonc NGS, and returns the appropriate comments. To update this website, the excel document should be uploaded any time a change to comments is made. Other files in this repository are images that are used to supplement comments.
